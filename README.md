# Market Data Downloader (Android)

Нативный Android-проект на Kotlin: MOEX ISS и OKX public REST API, свечи OHLCV, пагинация и сохранение CSV через системный диалог Android.

## Сборка APK
1. Установите Android Studio на ПК и Android SDK Platform 35.
2. Откройте папку проекта `MarketDataDownloader` в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите Build → Build APK(s).
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется интернет. API-ключи для публичных исторических свечей OKX не нужны.

## Важно
- Для MOEX выберите правильный рынок: «MOEX — акции» или «MOEX — фьючерсы». Доступность истории зависит от инструмента и интервала.
- Для OKX вводите `BTC-USDT` или `BTC/USDT`; приложение нормализует `/` в `-`.
- Исторические свечи MOEX могут отличаться по доступным интервалам/рынкам. Для ряда фьючерсов тикер/схема ISS может потребовать уточнения.
- «Вся история» — практический диапазон с 2016 года для MOEX и с 2017 года для OKX, не обещание полной истории инструмента.
- Перед использованием в торговых исследованиях сверяйте данные с биржей. Приложение скачивает данные, не даёт торговых рекомендаций.
